## Acerca de SFML

SFML (Simple and Fast Multimedia Library) es una biblioteca multimedia escrita
principalmente en C++ que proporciona interfaces para gráficos, ventanas,
audio, redes y funcionalidades del sistema.

La documentación presentada en este sitio fue generada a partir del código
fuente de SFML correspondiente al commit
`2124d5fe87412ac1cf8e20de282502a75039efcf`.
